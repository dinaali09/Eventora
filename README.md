# Eventora Pro — Advanced PWA Main Project

Eventora is a professional event-planning PWA built with Flask and SQLite. It combines vendor discovery with a personal event command center.

## Main Features
- Vendor marketplace with 18+ service categories
- Real vendor photography using curated image URLs
- Search, category/location filters and sorting
- Vendor detail pages, ratings, reviews and favourites
- Event creation and event timeline
- Personal dashboard / planner
- Budget overview: total budget, spent and remaining
- Spending mix by category
- Expense tracking with event selection and delete action
- Booking pipeline with Pending/Confirmed status
- Saved vendor shortlist
- Upcoming-event card
- Admin overview
- PWA manifest and service worker
- Responsive desktop/mobile layout

## Run Without Typing
1. Extract this ZIP.
2. Open the extracted folder.
3. Double-click `run_eventora.bat`.
4. The browser opens at `http://127.0.0.1:5000`.

If Windows shows a security prompt, choose **Run** / **Open**.

## Technology
Flask, SQLite, HTML5, CSS3, JavaScript, PWA Service Worker.
